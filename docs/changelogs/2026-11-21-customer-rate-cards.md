# Customer rate cards

- Story: [US-018](../stories/US-018-customer-rate-cards.md)
- Customer users manage company rate cards (profile, user type, company restrictions, minimum price, active, zone lanes)
- API: `GET/POST /api/rate-cards`, `GET/PUT /api/rate-cards/{id}`, `GET /api/rate-cards/company-options`
- UI: `/app/rate-cards` list (AG Grid + compact data list), create/edit form with zone rate table
