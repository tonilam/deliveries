Loadplanner README.md

Get everything running on your machine.

Laravel 13 API + Angular 22 SPA, with MySQL from Docker Compose. Follow the steps below once, then use the daily commands to develop.

First-time setup

From the repo root. Keep two terminals handy for API and web after MySQL is up.

  1. 1

    Clone & root env

    Copy the shared Compose/AWS defaults, then start MySQL on port 3307.

    cp .env.example .env
make up

    Credentials: database loadplanner, user loadplanner, password secret · host 127.0.0.1:3307

  2. 2

    API (Laravel)

    Install PHP deps, generate APP_KEY, migrate, then serve on :8000. 

    cp apps/api/.env.example apps/api/.env
cd apps/api && composer install && php artisan key:generate
cd ../..
make migrate
make serve-api

    Host-run API uses DB_HOST=127.0.0.1 and DB_PORT=3307 (already in apps/api/.env.example).

  3. 3

    Web (Angular)

    Install npm packages and start the SPA on :4200. Requests to /api are proxied to Laravel. 

    cd apps/web && npm install
cd ../..
make serve-web
  4. 4

    Git pre-commit hook

    Formats staged web files with Prettier and staged PHP with Pint before each commit.

    make hooks-install

Verify it works

With MySQL, API, and web all running, check these URLs.

  • API health: http://127.0.0.1:8000/api/health
  • Angular app: http://localhost:4200 — should show API status via the proxy
  • Admin portal: create a user first (see First admin user), then sign in and open /admin

First admin user

Admins are never auto-created on Google or Apple SSO. Provision the first admin in the database after migrations, then use the same shared /login as customers (you’ll be redirected to /admin).

Run this once from the repo root. Change name, email, and password to your values. Use the same email you’ll use for Google sign-in if you plan to use SSO. 

cd apps/api && php artisan tinker --execute="
\App\Models\User::factory()->admin()->create([
  'name' => 'Admin',
  'email' => 'you@yourcompany.com',
  'password' => 'Password1!',
]);
"

SSO-only admin (no password): swap ->admin()->create for ->admin()->withoutPassword()->create and omit password. The row must still exist before the first Google login.

If ADMIN_EMAIL_DOMAIN is set in apps/api/.env, the admin email must match that domain and Google must return a matching hd claim when present.

Daily commands

After the first setup, a typical day looks like this.

make up          # MySQL (if not already running)
make serve-api   # terminal 1 — http://127.0.0.1:8000
make serve-web   # terminal 2 — http://localhost:4200
make down        # stop Compose when you are done
Task Command
Install API deps make api-install
Install web deps make web-install
Run migrations make migrate
MySQL logs make mysql-logs
Format / lint web cd apps/web && npm run format · npm run lint
Format / lint API cd apps/api && composer format · composer lint
Rector (dry-run) cd apps/api && composer rector

Optional: Truckit component library

Shared Angular UI from AWS CodeArtifact. Skip this until you need the design system. 

aws codeartifact login --tool npm \
  --domain truckit --domain-owner 349139559071 \
  --repository component-library --region ap-southeast-2

cd apps/web && npm install truckit-component-library

Prepend node_modules/truckit-component-library/styles/tokens.css in apps/web/angular.json styles. Storybook: component.truckitmetro.com/storybook.

Troubleshooting

Common first-day friction and what to check.

  1. ?

    API health fails / DB connection refused

    Confirm Compose MySQL is healthy (make up, make mysql-logs). Host API must use port 3307, not 3306.

  2. ?

    SPA cannot reach API

    Keep make serve-api running. The Angular proxy only forwards to 127.0.0.1:8000.

  3. ?

    Pre-commit says prettier/pint missing

    Run make web-install and/or make api-install, then make hooks-install again.

  4. ?

    Port already in use

    Free 3307 (MySQL), 8000 (API), or 4200 (web), or change the serve commands in the Makefile.
